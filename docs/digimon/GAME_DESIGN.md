# Game Design

Digimon Digital Nexus is an original Digimon RPG built on
`pokeemerald-expansion`. Pokémon engine internals remain intact where practical,
while player-facing systems transition to Digimon concepts incrementally.

The game is built as vertical slices. Every mechanic must first work for a small
set of Digimon before its roster or world scope expands. The first slice is Agumon:
a Fire-element Rookie with a Vaccine Attribute. Attribute combat, Scan Data,
partners, and Digivolution are deliberately outside the first prototype.
