# File Island

New games start in Primary Village (the Village of Beginnings) instead of the
Hoenn truck. The island has 19 maps in `gMapGroup_FileIsland`:

```text
                    [Mt. Infinity] ── cave
                          │
   [Freezeland] ──── [Overdell] ──── [Factorial Town]
     │  └ Freeze Cavern   │                │  └ Recovery Terminal
   [Dragon Eye Lake] ─ [Native Forest] ─ [Gear Savanna]
                      │  └ Ancient Ruins 1F → 2F → Sanctum (Kuwagamon)
                          │                └ Drill Tunnel
                  [Primary Village]  (Recovery Terminal, shop, Elder's house)
                          │
                     [File Beach]
```

## Playtest route

1. Take the Digivice in Primary Village (the eight-way starter choice, no
   rescue battle). The village exits are blocked until the player has a partner.
2. Native Forest (wild Lv 3–10, mostly 3–6) → the rocky mound → Ancient Ruins 1F/2F
   (Lv 9–17, rising toward Digivolution at 16; DigiEgg: Courage on 2F) → Ruins Sanctum.
3. Kuwagamon Lv 18. Winning sets `FLAG_DEFEATED_KUWAGAMON`, shows the
   end-of-playtest message and returns the player to the village. The
   thickets on the forest's north, east and west paths disappear, opening
   the rest of the island (Lv 16–37).

The DigiEgg and DNA Charge items are found on the island: Courage (Ruins 2F),
Sincerity (Overdell), Knowledge (Freeze Cavern), Miracles (Mt. Infinity cave),
DNA Charge (Drill Tunnel).

## Generator

Maps are generated by `tools/digimon_maps` from the specs in
`tools/digimon_maps/island/`. Run it in the dev container:

```bash
cd tools/digimon_maps && python3 build.py --preview /tmp/island
```

Each spec draws terrain classes (floor, tall grass, water, sand, ice, wall,
trees) on a canvas. `autotile.py` turns classes into metatiles using rules
learned from the Hoenn maps that share the tileset; trees use rules measured
from ~12,000 tree tiles. Buildings and cave mouths are stamps copied from
Hoenn maps. The generator writes layouts, `map.json`, the map group, MAPSEC
names, wild encounters and the script includes. `scripts.inc` files are
hand-written and never overwritten. `render.py LAYOUT_ID out.png --grid`
previews any layout without an emulator.

NPCs are Digimon with Digimon World DS field sprites: Leomon guides the
village, Jijimon is the elder, Digitamamon runs the shop, Monzaemon heals at
both Recovery Terminals (lab interiors), Andromon is in Factorial Town and
Kuwagamon waits in the Sanctum. Items are data chips instead of Poké Balls.

Six Tamers (class TAMER, Emerald kid/hiker sprites) line the slice route, using
the spare trainer-flag slots 855–860 so the save layout is unchanged:

| Tamer | Where | Team |
| --- | --- | --- |
| Kai | Native Forest, main path | Gazimon 5 |
| Mia | Native Forest, south-west grass | Floramon 6, Lalamon 7 |
| Ren | Native Forest, path to the ruins | Elecmon 8, Goblimon 9 |
| Oda | Ancient Ruins 1F | Gotsumon 11, Hagurumon 12 |
| Sora | Ancient Ruins 2F | Bakomon 13, Ghostmon 13, DemiDevimon 14 |
| Jun | Ancient Ruins 2F, by the Sanctum ladder | Tsukaimon 15, Phascomon 16 |

`make roster-check` also runs `tools/digimon_maps/test_island.py`, which checks
that every warp lands on a warp that leads back, connections are mirrored, and
Tamer teams stay in their level band.

Tilesets reuse Emerald's until Milestone 29. Known placeholder: the shop uses
the Mart interior. Engine-wide Pokémon
wording (battle text, bag pockets, summary screens) is plan step 7.
